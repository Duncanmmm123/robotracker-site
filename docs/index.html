Set up your first tracker

Start in the Discord server where you want alerts delivered.

  1. Install RoboTracker. Use Add to Discord, pick a server you manage, and review the permissions.
  2. Run /setup. Check channel permissions and follow the setup prompts.
  3. Run /track-account. Enter a Roblox username or ID, confirm the profile, and select what to monitor.
  4. Choose who gets alerts. Open /alerts settings and review recipients under /alerts recipients list.

Common questions

Why is a friend list or game missing?

Roblox can return a count without names or a presence state without game details. RoboTracker displays the information the API actually provides. Your signed-in Roblox view may show more.

Why didn’t I get an alert immediately?

The first check establishes a baseline. Later alerts depend on Roblox samples, your settings and cooldown, and Discord delivery. Check /status and confirm the tracker channel is reachable.

Do I need to give RT administrator access?

Administrator access is unnecessary for the default install. The bot needs permissions including Manage Channels and Manage Roles to create and configure tracker channels. Review channel access after setup.

How do I remove my data or report misuse?

Run /privacy remove in a server where tracker commands are enabled, then follow the profile verification steps. If you can’t access the command or you’re reporting misuse, open a private support ticket. See the removal guide.
